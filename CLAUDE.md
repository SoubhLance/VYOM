# CLAUDE.md — VYOM

VYOM is a Bhagavad Gita question-answering app. The backend is FastAPI with
BGE-M3 search over Qdrant, multi-query retrieval, Groq generation and a quote
verifier. The frontend is Vite, React and TypeScript, with a video gateway, a
cream-and-gold sanctuary dashboard, the Sacred Book reader and per-shloka
recitation clips.

## Layout
- `backend/api/main.py` holds `/api/ask` and `/api/health`. `api/clips.py`
  mounts `/audio` (from `backend/data/multimodal/source/assets/audio`) and
  attaches clips to sources.
- `backend/retrieval/` holds search, multi-query (`multi.py`), prompts
  (`prompt_v2.py`), the router and `verify_quotes.py`.
- `backend/llm/client.py` tries providers in the order set by `LLM_PROVIDERS`
  (default groq, gemini, ollama). Groq is primary. Gemini is deferred.
  The Groq model defaults to `openai/gpt-oss-120b` (llama-3.3-70b is
  Enterprise-only now). gpt-oss always reasons: every call sends
  `reasoning_effort="low"`, `include_reasoning=False`, `max_tokens=1800`.
- `backend/data/processed/verses.jsonl` is the canonical verse text (701).
- `backend/data/multimodal/verse_clips.json` maps verse IDs to recitation
  clips (700 verse mp3s plus 18 chapter mp3s).
- `frontend/src/services/audioCoordinator.ts` makes playback exclusive and
  pauses background music while a clip plays.
- `frontend/src/data/shlokaDirectory.json` and `recitationIndex.ts` drive the
  reader's recitation.
- `frontend/public/translations/chNN.json` is generated by
  `frontend/scripts/export_translations.py` from `verses.jsonl`. Don't
  hand-edit it.
- `backend/_scratch/` and the `*INTEGRATION_NOTES*.txt` files are historical.
  Both integration patches are already applied in `main.py`.

## Commands
`venv/` is a conda environment, so the interpreter is `venv\python.exe`.
There is no `venv\Scripts\python.exe`.
- Backend tests: `.\venv\python.exe -m pytest backend/tests` (228 tests,
  all passing as of 2026-11-12).
- Run both servers on Windows: `npm run dev:win` (backend :8000, frontend
  :5173; Vite proxies `/api` and `/audio`).
- Frontend build or type-check: `npm run build`.
- Lint: `npm run lint:frontend`.

## Known issues
- `shlokaDirectory.json` has 80 real Sanskrit mismatches against
  `verses.jsonl`: speaker lines, and verses shifted by half a verse. The
  backend copy is canonical. Audio alignment must be checked before any text
  fix.
- `backend/.env` uses `GEMINI_MODEL="gemini-2.5-flash"`, but `.env.example`
  and the code default in `llm/client.py` still say `gemini-1.5-flash`.
- Re-index after typo fix: 6 Sanskrit typos in `verses.jsonl` were fixed on
  2026-11-11 (1.26, 1.34, 4.29, 4.31, 9.25, 10.29; backup at
  `verses.jsonl.bak1`). The Qdrant index in `backend/qdrant_data/` was built
  from the old text and has not been rebuilt.
- Groq rate limits on this account: 8K tokens/minute, 1K requests/day
  (from response headers; docs also list 200K tokens/day). One multi
  question uses about 5.8K tokens (splitter + answer), so roughly one
  question per minute before a 429.
- `RecitationSanctuary.tsx` is not mounted anywhere.
- `font-cinzel-dec` points at Cinzel Decorative, which is not loaded.
